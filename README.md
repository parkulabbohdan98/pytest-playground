# pytest-playground

Навчальна пісочниця для розбору pytest.

## Що тут є

- `test_with_pytest.py` / `test_with_unittest.py` — порівняння виводу при падінні
- `test_assert_examples.py` — прості assert-вирази
- `test_fixture_demo.py` — фікстури
- `test_parametrize_demo.py` — параметризовані тести

## Запуск

```bash
source .venv/Scripts/activate
pytest -v
```

Два тести падають навмисно — це демонстрація виводу.
